# 09.01 - MODELLO DI ANALISI DELLE PIATTAFORME

## Scopo

Il presente documento definisce il modello standard utilizzato per analizzare qualsiasi piattaforma turistica, PMS, OTA, CRM, Channel Manager o Booking Engine.

Ogni piattaforma dovrà essere analizzata utilizzando esclusivamente il presente schema.

L'obiettivo è garantire uniformità nell'analisi e rendere confrontabili le diverse piattaforme.
